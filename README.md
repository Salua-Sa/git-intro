# Git Intro

This project is a basic introduction to Git and GitHub.

It contains simple text files used to practice creating files, tracking changes, committing updates, working with branches, and merging changes.

## Files

| File | Purpose |
|---|---|
| `.gitignore` | Defines files or folders that Git should ignore |
| `greeting.txt` | Practice file for basic Git tracking and commits |
| `improvement.txt` | Practice file for making and committing updates |
| `message.txt` | Practice file created or updated during branch and merge exercises |

## Git Concepts Practiced

- Creating a Git repository
- Tracking file changes
- Using `git status`
- Adding files with `git add`
- Creating commits with `git commit`
- Working with branches
- Merging branches
- Pushing changes to GitHub
- Using `.gitignore`
